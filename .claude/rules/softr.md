# Softr

- Any Softr build work — blocks, custom code, native styling — **always uses the `softr-vibe-coding` skill**. Never freehand a Softr block.
- Before styling work: if `DESIGN.md` exists at the project root, it is the source of truth. If it doesn't and styling is starting, run the `building-design-md` skill first.
- Blocks are saved under `Assets/Softr App/{Page Name}/` — see `.claude/rules/asset-creation.md`.
