# Softr

- Any Softr build work — blocks, custom code, native styling — **always uses the `softr-vibe-coding` skill**. Never freehand a Softr block.
- Before styling work: if `DESIGN.md` exists at the project root, it is the source of truth. If it doesn't and styling is starting, make it first: Step 1 of the `softr-vibe-coding` skill (dembrandt), or the `building-design-md` skill if it is installed.
- Blocks are saved under `Assets/Softr App/{Page Name}/` — see `.claude/rules/asset-creation.md`.
- Use Opus for orchestration and Sonnet agents for implementation. This is the one exception to the Sonnet default in the [Project Scaffolding SOP](https://coda.io/d/_deZKBjDZAhI/AI-Claude-Project-Scaffolding_suBPVZkm).
