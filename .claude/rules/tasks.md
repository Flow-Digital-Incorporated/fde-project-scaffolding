# Task Management

All tasks live in [TASKS.md](../../TASKS.md). Never track work anywhere else.

## Creating tasks
- New tasks are **always created in TASKS.md**, under the priority section they belong in, newest at the top of their section.
- **AI assigns the priority** when creating a task; the FDE can override it.
  - **P0 — Critical:** blocking the client or the engagement; drop everything.
  - **P1 — High:** needed this week / next session.
  - **P2 — Medium:** normal backlog.
  - **P3 — Low:** nice-to-have, someday.

## Task format
Every task uses this structure:

```
### {Task name}
- **Summary:** one line.
- **Description:** what needs to be done, concretely.
- **Source:** where this task came from. If it came from a call, name the exact file — e.g. `Fathom recordings/2026-08-12 - Kickoff.md` — so additional context can be retrieved from it when needed.
```

## Completing tasks
- Completed tasks **move to the Archive section** at the bottom of TASKS.md, prefixed `✅ YYYY-MM-DD`, newest first.
- Never delete a task. Cancelled tasks also move to Archive, prefixed `❌ cancelled` with a one-line reason.
