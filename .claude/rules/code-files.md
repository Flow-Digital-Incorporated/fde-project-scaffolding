# Code Files

**Every code file created in this project is a `.jsx` file — no exceptions.** Airtable automation scripts, Softr Vibe Coding blocks, Zapier code steps, custom HTML/CSS embeds: all `.jsx`. Never create `.js`, `.ts`, `.html`, or `.css` files.

Start each file with a short header comment (in the comment syntax of its paste target — `/** */` for JS, `<!-- -->` for HTML content): what it is, where it's deployed, and the date it last matched the deployed version.
